# Паспорт проекта
## Название проекта
Онлайн-школа английского языка
## Предметная область
Сервис будет заниматься предоставлением материала и практических заданий по английскому языку. С сайтом будут работать преподаватели по английскому языку, ученики, администраторы. На странице должны отображаться курсы по выбранной теме, практическое задание для закрепления знаний, кнопка регистрации и записи на курс. У преподавателя отображаются количество учеников, их успеваемость, класс/курс, расписание, и выполненные работы. У ученика отображаются его успеваемость, преподаватель, расписание, список тем. Основное действие пользователя – записаться на курс как ученик или преподаватель. Задачи администратора – Вести учет работы преподавателей, разделять учеников на группы по их уровню знаний.
## Проблема
Проблема которую решает проект – невозможность изучения английского либо из-за отсутствия программы в образовательном учреждении, невозможности посещать занятия либо из-за плохого качества преподавания.
## Цель проекта
Цель проекта – разработать веб-сайт для изучения английского языка, позволяющий пользователям дистанционно изучать язык в соответствии с их уровнем знаний и этапом обучения, а администратору – управлять группами учеников, и практическими заданиями.
## Целевая аудитория
-ученики, плохо знающие английский
-ученики, без возможности посещать занятия в своем образовательном учреждении
-Учителя, обучающие учеников заочно.
## Роли пользователей
Гость - просмотр публичной части, регистрация, запись на курс.
Ученик - Просмотр лекций и выполнение практических работ.
Преподаватель - отправлять в группу темы для изучения, вести отчет успеваемости группы.
Администратор - добавлять учителей и учеников в систему, распределять их по группам.
## Контентная сущность
Курс
## Операционная сущность
Запись на курс
## Основные функции
Гость - Просмотр главной страницы, Регистрация/запись на курс, Выбор уровня знаний.
Ученик - Просмотр доступных предметных тем, Просмотр лекций,Выполнение практических работ, Связь с учителем, Выход из системы, Выписывание из курса.
Преподаватель - Связь с учениками, Просмотр успеваемости, Открытие тем ученикам.
Администратор - Добавление учеников и преподавателей в систему, Отчет о работе преподавателей
