# Пользовательские сценарии
Гость - заходит на сайт, переходит на страницу регистрации, указывает уровень знаний, записывается на курс.
Ученик - переходит на страницу группы, открывает тему, читает лекцию, выполняет практику, види результат.
преподаватель - переходит на страницу группы, переходит на страницу практик, проверяет практики, записывает в журнал, открывает новую тему.
Администратор - открывает страницу пользователя, проверяет заполненость групп, сравнивает уровень знаний, добавляет в подходящую группу.
